# 内容识别与效果路由矩阵

> 规则编号与 `scripts/effect_router.py` 输出的 `basis` 一致。每条规则三件套：
> **命中条件**（基于可观测量，不按页序号猜）/ **推荐效果** / **明确不要用什么 + 反例形态**。
> 识别信号重叠或稀疏时，输出 `confidence: low` 并落到保守档，不猜页型。

## 1. 识别口径

- 可观测量：字号分布、文本框面积与占比、数字 token 比例、表格行数与表头词成格、
  时间词正则命中、步骤编号与箭头成链、左右等高容器对齐模式、引号与收束词、背景类型。
- 模板文本（页脚页码、课程名页脚、装饰线、行动线备注、kicker）不参与页型规则匹配。
- 页型优先级：结尾 → 封面 → 章节过渡 → 引语 → KPI → 表格清单 → 时间线 → 流程步骤
  → 双栏对比 → 并列卡片；高优先级命中且无竞争页型判 `high`，有竞争或特征稀疏判 `low`。

## 2. 页型规则

### 2.1 COVER-1 封面

- **命中条件**：最大字号 run ≥ 30pt；正文块 ≤ 14；容器 < 5；无 ≥ 2 个大字号数字。
- **推荐效果**：标题 fade / wipe_l 入场，环簇或光点常驻；转场 `circle` / `wedge`；
  环境动效基线一条即可，不铺满装饰。
- **不要用什么 + 反例形态**：不要给封面挂逐行滑入的正文批次；不要把标题数字当 KPI
  反复 grow。反例：封面页被元数据行（姓名、学号、班级）撑出多个容器，导致误判为卡片网格；
  大标题字号被元数据字号稀释而漏判封面。

### 2.2 SEC-1 章节过渡

- **命中条件**：命中章节标记（`PART 数字` / `第 N 章` / `章节`）；正文块 ≤ 4；容器 < 3。
- **推荐效果**：章名 fade 入场，环簇自转常驻；自带 kicker 文本槽；转场 `wheel4` / `wedge`。
  稀疏装饰页可走整页导入复用母题，导入后只换 kicker 与章名文本。
- **不要用什么 + 反例形态**：不要在过渡页铺数据条目；不要省略 kicker 槽，否则章节编号
  在读者眼里从过渡页之后才开始。反例：过渡页混入三条要点，被误判为卡片清单。

### 2.3 QUO-1 引语页

- **命中条件**：引号命中；无数字 token；正文块 ≤ 4；正文字数 ≥ 30。
- **推荐效果**：引语整句 fade 或 reveal 入场，署名晚 150—300ms；转场 `fade` / `reveal`；
  不挂常驻环簇，避免抢引语。
- **不要用什么 + 反例形态**：不要把引语拆成逐词飞入；不要给引号加 grow 强调。反例：引语中
  出现年份或编号被当成 KPI，引语页误判为数字页。

### 2.4 KPI-1 KPI 数字

- **命中条件**：大字号数字 run（≥ 20pt）≥ 2 个；或有 1 个大字号数字且数字 token ≥ 3、
  数字密度 ≥ 0.08。
- **推荐效果**：数字 grow 回弹一次；数字载体先入场，标签文字同批 fade 晚 150—450ms；
  转场 `split_h` / `blinds_h`。
- **不要用什么 + 反例形态**：强调只绑数字本身，不绑卡片容器；不要对整张卡片 blink。反例：
  表格页的小字号学分 / 学时数字被密度规则当成 KPI；大字号标题里的编号被当成大数字。

### 2.5 TBL-1 表格清单

- **命中条件**：真实 `a:tbl` / graphicFrame；或表头词（课程、学分、序号、问题、方案、科目、
  周次、模块、对比、类别）出现在 ≤ 8 字的短标签形状里，且短标签 ≥ 4、正文块 ≥ 7。
- **推荐效果**：表头先入场，行按批 fade / wipe_u 逐行错开 120—300ms；转场 `fade` / `wipe_u`；
  表格页不强制常驻环簇，避免压住行文字。
- **不要用什么 + 反例形态**：不要整表同帧 fade 铺满；不要给单元格文字挂位移。反例：表头词
  出现在正文叙述句里（非表头行）被误判为表格；行标签短文本少，表格被误判为并列卡片。

### 2.6 TIME-1 时间线 / 学期推进

- **命中条件**：时间词命中（学期、周次、阶段、步骤、季度）；且步骤编号 ≥ 2 或正文块 ≥ 5。
- **推荐效果**：时间轴先画，节点按时间序 wipe_l / fly_up 依次入场；当前阶段 blink 或
  grow 一次；转场 `wipe_l` / `pull`。
- **不要用什么 + 反例形态**：时间词出现在行动线备注或课程名叙述里时，不计入时间线判定；
  不要把学期推进做成左右横滑的并列卡片。反例：行动行里的「每学期末自查」触发时间线误判；
  流程箭头页混入「阶段」字样被当成时间线。

### 2.7 PROC-1 流程步骤

- **命中条件**：步骤编号 ≥ 3，或箭头成链 ≥ 2；正文块 ≥ 5。
- **推荐效果**：步骤沿箭头方向依次入场（fly_up / wipe_l），当前步骤强调一次；
  转场 `pull` / `conveyor`。
- **不要用什么 + 反例形态**：不要在步骤之间堆叠同方向滑入；箭头装饰不单独强调。反例：
  「路线 / 流程」等叙述词被当成时间词；三栏并列里出现箭头被当成流程链。

### 2.8 CMP-1 双栏对比

- **命中条件**：左右两个等高容器对齐（左块 x < 6000000，右块 x ≥ 6000000），且命中对比词
  （对照、优劣、正反、vs、两组、对比），或恰好两个大容器。
- **推荐效果**：左栏先入、右栏晚 200—350ms；两侧同预设族对称；转场 `cover_l` / `split_h`。
- **不要用什么 + 反例形态**：不要让两栏用不同方向的入场打架；不要在对比页加第三条并列泳道。
  反例：三栏结构被左右二分判成双栏；两栏文字长短悬殊仍按等高容器处理。

### 2.9 CARD-1 并列卡片

- **命中条件**：容器 ≥ 3（几何面积门：cx ≥ 1500000、cy ≥ 400000、cx < 11000000），
  各带文字，正文块 ≥ 4。
- **推荐效果**：卡片按批拆组入场；容器先入，文字同批 fade 晚 150—450ms；卡片间错开发
  120—300ms；转场 `cover_l` / `split_h`。
- **不要用什么 + 反例形态**：跨批卡片的文字不得共用一个组节点；标签条、分隔线、行底不算
  卡片容器。反例：整页文字共用单个组节点，跨批时第一击看到空白卡；元数据小方块被面积门
  之外的计数误当成卡片。

### 2.10 END-1 结尾

- **命中条件**：收束词命中（谢谢、总结、三年之后、致谢、结尾、展望）；无数字 token。
- **推荐效果**：核心结论或收束语单次强调；转场 `zoom_t` / `fade`；稀疏装饰可整页导入。
- **不要用什么 + 反例形态**：结尾不要再起新的数据批次；不要常驻多条环簇。反例：致谢页带
  联系方式数字被误判为 KPI。

## 3. 路线规则

### 3.1 R3 背景媒体阻断

- **命中条件**：`p:bg` 内存在 `a:blipFill` / `a:blip` 整页照片媒体。
- **推荐处置**：路线判 `block`；先声明烘焙像素处置（replace / keep / block）与基调
  recolor 路径，补齐后再定路线。`check_slide` 先核对媒体与烘焙文字、目标基调与重着色映射。
- **不要用什么 + 反例形态**：`useBgFill` 依赖重、烘焙像素主导的页面不得整页导入；替换背景
  后须确认不残留源媒体、无悬空 rels、Content_Types 同步、`ppt/media` 无孤儿图片。反例：
  背景照片上的像素文字被新背景覆盖后残留半透明轮廓；媒体替换后 rels 悬空导致打开报错。

### 3.2 BUILD-1 原生重建

- **命中条件**：内容结构页（KPI、表格、时间线、流程、对比、卡片、正文），非整页照片背景。
- **推荐处置**：走原生构建；批次结构（角色 + 数量 + 预设族 + 延迟区间）直接喂给 build 脚本；
  L0 安全层打底，L1 仅作同组点缀。
- **不要用什么 + 反例形态**：结构必须大改的装饰页不要硬走导入；批次数量与页内元素数不符时
  先拆页，不要把超量形状压进一批。

## 4. 基调与规模约束

- **字数上限**：单块文本 ≤ 60 字；超出先按句拆文本位再编排，不整段挂入场。
- **形状数上限**：单页 ≤ 40 个形状；超出考虑拆页，检查器会在 `cautions` 提示。
- **背景依赖**：页面填充或 `useBgFill` 依赖整页照片媒体时，不得整页导入，先过 R3 阻断口径。
- **深色底**：深色基调不用浅色系配件（浅灰描边、低饱和浅色块）；重着色保留颜色变换节点，
  冲突无确定性消解路径时阻断。
- **反例形态**：深色底上挂浅底卡片而无对比层级；一页内混合多套入场方向；超量内容挤在
  同一批，放映时只有描边在动。

## 5. 保守档口径

- 信号不足或规则重叠：`confidence: low`，页型落到次优保守档（默认并列卡片），批次按最少
  批次方案给，路线优先 `native_rebuild`，不给出高冲击导入建议。
- 工具内无法证伪的项（真实放映观感、custGeom 在特定渲染器的包围盒填充行为）不在计划里
  下结论，留到目标机 F5 复核。
