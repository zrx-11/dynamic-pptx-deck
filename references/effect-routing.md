# 内容识别与效果路由矩阵

> 规则编号与 `scripts/effect_router.py` 输出的 `basis` 一致。每条规则四件套：
> **识别特征**（可观测量：字号分布、形状几何、表格 / 图表存在性、关键词正则、容器数量与对齐模式）/
> **可用版式骨架**（指向 `layout-recipes.md` 具体节号）/
> **可用效果族**（指向 `effects-catalog.md` 或 `effect-recipes.md`，写清引擎要求）/
> **明确禁用项 + 反例形态**（可判定，不写事故叙事）。
> 识别信号重叠或稀疏时，输出 `confidence: low` 并落到保守档，不猜页型。
> 推荐族默认按效果优先档输出（`engine_profile: effect_first`）；高版本项逐条标注 2019 降级
> 行为，兼容优先档（`--engine compat`）只下发标准 DrawingML 安全族。

## 1. 识别口径

- 可观测量：字号分布、文本框面积与占比、数字 token 比例、表格 / 图表存在性、表头词成格、
  时间词正则、步骤编号与箭头成链、左右等高容器对齐模式、引号与收束 / 感谢词、图片数量与面积、
  背景类型。
- 模板文本（页脚页码、课程名页脚、装饰线、行动线备注、kicker）不参与页型规则匹配。
- 数字块口径：短文本（≤12 字）且以数字 / 比较符号开头才计为数字块；叙述句 / 标题里夹带的
  数字不计。纯编号圆牌（01–12 / 一–六）是卡片序号徽章，不计入任何数字块。
- 页型优先级：结尾 → 致谢 → 封面 → 章节过渡 → 引语 → 目录 → KPI → 指标带 → 趋势图 →
  风险提示 → 对比表 → 表格清单 → 组织结构 → 时间线 → 流程步骤 → 双栏对比 → 案例卡 →
  结论清单 → 图集 / 图墙 → 并列卡片；高优先级命中且无竞争页型判 `high`，有竞争或特征稀疏判 `low`。

### 1.1 易混页型分界（可判定阈值）

- **KPI vs 指标带**：主角数字 run ≥ 28pt 且数字块 ≤3 判 KPI；无主角数字、16–27pt 中小数字块
  ≥4 横排判指标带。编号圆牌不计数字块。
- **结尾 vs 致谢页**：结尾命中收束结论词（总结、三年之后、结尾、展望）并列成果条目；致谢页
  命中感谢 / 联络词（谢谢、感谢、致谢、敬请指正、联系方式、邮箱、电话、微信、QQ），无结论条目、
  无主角数字。
- **双栏对比 vs 对比表**：双栏对比是左右两个自由等高容器各放一组要点；对比表是成行成对的
  双侧列头单元格（同一行左右对齐）。
- **并列卡片 vs 案例卡**：并列卡片 ≥3 张等权并置；案例卡是 1–2 个被展开的主角。
- **图墙 vs 轮播**：图墙是同页 ≥3 张内容图片并置；轮播是跨页逐图换位（R14 / R18 配方）。
- **表格清单 vs 对比表 vs 风险提示**：表格清单为通用字段行；对比表双侧列头成对；风险提示
  风险词命中且风险—对策成对成行。

## 2. 页型规则

### 2.1 COVER-1 封面

- **识别特征**：最大字号 run ≥ 30pt；正文块 ≤ 14；容器 < 5；无 ≥ 2 个大字号数字块。
- **可用版式骨架**：`layout-recipes.md` §2（左侧信息块 + 右侧转盘）；照片底叠加见 §1c。
- **可用效果族**：标题 fade / wipe_l 入场，环簇或光点常驻（`effects-catalog.md` §2 安全族、§7
  环境母题，both）；转场 `circle` / `wedge`。
- **不要用什么 + 反例形态**：不要给封面挂逐行滑入的正文批次；不要把标题数字当 KPI 反复 grow。
  反例：封面页被元数据行（姓名、学号、班级）撑出多个容器，误判为卡片网格；大标题字号被元数据
  字号稀释而漏判封面。

### 2.2 SEC-1 章节过渡

- **识别特征**：命中章节标记（`PART 数字` / `第 N 章` / `章节`）；正文块 ≤ 4；容器 < 3。
- **可用版式骨架**：`layout-recipes.md` §5（章节过渡：大号编号 + 章名 + 引导语）。
- **可用效果族**：章名 fade 入场，环簇自转常驻；前后章名 / 编号同名同类型时优先 Morph 配对补间
  （`effects-catalog.md` §11，effect_first；2019 剥离走 fallback fade）；转场 `wheel4` / `wedge`；
  稀疏装饰页可整页导入复用母题。
- **不要用什么 + 反例形态**：不要在过渡页铺数据条目；不要省略 kicker 槽。反例：过渡页混入三条
  要点，被误判为卡片清单；缺 kicker 槽时章节编号在读者眼里从过渡页之后才开始。

### 2.3 QUO-1 引语页

- **识别特征**：引号命中；无数字 token；正文块 ≤ 4；正文字数 ≥ 30。
- **可用版式骨架**：`layout-recipes.md` §4.13（居中大句 + 署名，四周留白）。
- **可用效果族**：引语整句 fade / reveal，署名晚 150—300ms（§2 安全族，both）；转场
  `fade` / `reveal`；不挂常驻环簇。
- **不要用什么 + 反例形态**：不要把引语拆成逐词飞入；不要给引号加 grow 强调。反例：引语中出现
  年份或编号被当成 KPI，引语页误判为数字页。

### 2.4 KPI-1 KPI 数字

- **识别特征**：主角数字块（自身字号 ≥ 28pt）1—3 个；或 ≥20pt 数字块 ≥2；或 1 个大字号数字
  且数字 token ≥3、数字密度 ≥0.08。数字块为短文本且以数字 / 比较符号开头。
- **可用版式骨架**：`layout-recipes.md` §4.6（并列大数字 + 小字注释）。
- **可用效果族**：数字载体 `zoom` / `zoom_rot` 入场后 `grow` 回弹一次；标签 fade 晚 150—450ms
  （§3 移植族，effect_first；兼容档只给 `zoom`）；转场 `split_h` / `blinds_h`。批次：
  `ambient → kpi_value → label → action`。
- **不要用什么 + 反例形态**：数字不要 fade 平铺入场；强调只绑数字本身，不绑卡片容器，不对整张
  卡片 blink。反例：数字与标签同帧淡入，重点读不出来；表格页小字号学分 / 学时数字被密度规则当成
  KPI；大字号标题编号被当成大数字。

### 2.5 MBD-1 指标带

- **识别特征**：无 ≥28pt 主角数字；16–27pt 中小数字块 ≥4，数字 token ≥4；「标签 + 值」双段
  chip 横排等距。
- **可用版式骨架**：`layout-recipes.md` §4.6b（指标带横排 chip）。
- **可用效果族**：数字 `zoom` / `fade` 成排入场，标签晚 150—350ms；重点指标单次 `grow`
  （§3，both；`zoom_rot` 仅 effect_first）；转场 `split_h` / `blinds_h`。
- **不要用什么 + 反例形态**：不要逐条 grow 回弹造成主角感混乱；不要把中小数字放大成主角仍按
  指标带排。反例：4 个以上大数字被当成一组 KPI；数字与标签同帧淡入，标签层级读不出来。

### 2.6 TRC-1 趋势图

- **识别特征**：存在真实图表对象（`c:chart` / 图表 graphicFrame）；或趋势词命中（趋势、增长、
  下降、同比、环比、走势、折线、柱状）且带轴 / 节点形。
- **可用版式骨架**：`layout-recipes.md` §4.7（坐标轴 + 系列 + 图例 / 数值标签）。
- **可用效果族**：基线 `wipe_l` 生长，系列逐组 `fade` / `wipe_u`，当前系列 `grow` 一次
  （§2 / §3，both）；转场 `wipe_u` / `checker`。
- **不要用什么 + 反例形态**：无真实数据不要手绘趋势走向；图表系列不挂位移类入场。反例：整图
  同帧 fade；峰值点之外的系列逐条 blink。

### 2.7 TBL-1 表格清单

- **识别特征**：真实 `a:tbl` / graphicFrame；或表头词（课程、学分、序号、问题、方案、科目、
  周次、模块、对比、类别）出现在 ≤8 字短标签里，短标签 ≥4、正文块 ≥7。
- **可用版式骨架**：`layout-recipes.md` §4.4（数据表格：表头列齐、细线分隔、隔行浅底）。
- **可用效果族**：表头一次 fade，行按 `wipe_u` 逐条错开 120—300ms（§2，both）；转场
  `fade` / `wipe_u`；不强制常驻环簇。批次：`header → rows`。
- **不要用什么 + 反例形态**：不要整表同帧 fade 铺满；不要给单元格文字挂位移。反例：表头词
  出现在正文叙述句里被误判为表格；行标签短文本少，表格被误判为并列卡片。

### 2.8 CMPT-1 对比表

- **识别特征**：真实表格且命中对比词 / 双侧列头词（优势、劣势、问题、对策、原方案、核对动作、
  方案 A、方案 B）；或双侧列头成格、成行 ≥2、短标签 ≥4，且无风险词。
- **可用版式骨架**：`layout-recipes.md` §4.4b（双侧列头、同行左右单元格对齐）。
- **可用效果族**：列头一次 fade，成对行 `wipe_u` 逐条入场，左右单元格同批（§2，both）；转场
  `fade` / `wipe_u`。
- **不要用什么 + 反例形态**：不要把成行成对结构拆成两个自由双栏容器；左右单元格不得错批入场。
  反例：左右单元格错批导致对照关系错位；两栏自由要点被当成对比表。

### 2.9 RSK-1 风险提示

- **识别特征**：风险词（风险、隐患、对策、警示、矛盾、不足、挑战、风险提示）出现在 ≤10 字
  短标签中；风险—对策成对成行 ≥2；正文块 ≥5。
- **可用版式骨架**：`layout-recipes.md` §4.9（顶部风险标记条 + 风险项 / 对策成对行）。
- **可用效果族**：风险标记 `grow_once` 单次，风险—对策成对同批入场，对策文字 fade 晚
  150—300ms（§3，effect_first；兼容档 `grow_once` 退回 fade）；转场 `cover_l` / `split_h`。
- **不要用什么 + 反例形态**：警示色只落风险标记，不铺满整页；对策文字不挂 grow / blink；标记
  不长闪。反例：风险词出现在长叙述 / 备注句里被误判为风险页；对策与风险标记同色同权重。

### 2.10 ORG-1 组织结构

- **识别特征**：组织词（部门、岗位、职责、主管、经理、团队、层级、主任、架构）出现在短标签；
  节点形（椭圆 / 圆牌）≥3。
- **可用版式骨架**：`layout-recipes.md` §4.8（根节点 + 分层下级 + 层级连线）。
- **可用效果族**：根节点 `zoom` 落位，连线 `path` 跟随，下级按层 `fly_up` / `fade` 错开
  （§2 / §3，both）；转场 `wheel4` / `wedge`。
- **不要用什么 + 反例形态**：层级连线缺失时不要按并列卡片排；跨层节点不得同批入场；下级节点
  不得先于根节点入场。反例：连线被漏画后整页按三张卡片编排；连线单独强调。

### 2.11 TIME-1 时间线 / 学期推进

- **识别特征**：时间词命中（学期、周次、阶段、步骤、季度）；步骤编号 ≥2 或正文块 ≥5；可带
  通栏主轴与节点形。
- **可用版式骨架**：`layout-recipes.md` §4.3（横向时间线：主轴 + 节点 + 阶段名 / 事项）。
- **可用效果族**：主轴 `wipe_l` 生长，节点 `fly` 错开 150—300ms，连线 `path` 跟随，节点文字
  fade；当前阶段 blink 或 grow 一次（§2 / §3，both）；转场 `wipe_l` / `pull`。批次：
  `ambient → axis → nodes → connectors → text`。
- **不要用什么 + 反例形态**：时间词出现在行动线备注 / 课程名叙述里时不计入；不要把学期推进做成
  左右横滑并列卡片。反例：行动行里的「每学期末自查」触发时间线误判；流程箭头页混入「阶段」
  字样被当成时间线。

### 2.12 PROC-1 流程步骤

- **识别特征**：步骤编号 ≥3，或箭头成链 ≥2；正文块 ≥5。
- **可用版式骨架**：`layout-recipes.md` §4.14（步骤块沿箭头 / chevron 成链）。
- **可用效果族**：步骤沿链 `fly_up` / `wipe_l` 依次入场，当前步骤强调一次（§2，both）；连线
  `path` 跟随；转场 `pull` / `conveyor`。
- **不要用什么 + 反例形态**：不要在步骤之间堆叠同方向滑入；箭头装饰不单独强调。反例：
  「路线 / 流程」叙述词被当成时间词；三栏并列里出现箭头被当成流程链。

### 2.13 CMP-1 双栏对比

- **识别特征**：左右两个等高容器对齐（左块 x < 6000000，右块 x ≥ 6000000），且命中对比词
  （对照、优劣、正反、vs、两组、对比），或恰好两个大容器。
- **可用版式骨架**：`layout-recipes.md` §4.2（双栏对照，栏头不同色标）。
- **可用效果族**：左栏 `fly_l` 先入，右栏 `fly_r` 晚 200—350ms，左右不同向不同速（§3，both）；
  转场 `cover_l` / `split_h`。批次：`left → right`。
- **不要用什么 + 反例形态**：禁止两栏同用 `fly_up`、同延迟同速；不要在对比页加第三条并列泳道。
  反例：两栏都 `fly_up` 且同延迟同速，对比关系出不来；三栏结构被左右二分判成双栏；两栏文字
  长短悬殊仍按等高容器处理。

### 2.14 CASE-1 案例卡

- **识别特征**：案例词（案例、实例、例如、背景介绍、做法、成效）出现在短标签；容器 ≤2；
  正文块 ≥3。
- **可用版式骨架**：`layout-recipes.md` §4.10（1–2 张主案例卡：标签 + 标题 + 背景 / 做法 /
  成效）。
- **可用效果族**：案例卡整体 `fly_up` / `cover_l` 入场，卡内文字同批 fade（§2 / §3，both）。
- **不要用什么 + 反例形态**：单案例不要撑出 ≥3 张等权卡片；卡内文字不挂位移；案例标签与正文
  不得错批。反例：案例卡容器 grow 回弹；一张案例被拆成三栏并列编排。

### 2.15 CONC-1 结论清单

- **识别特征**：结论词（结论、综上、小结、要点、建议清单、清单）出现在短标签；容器 <3；无表格、
  无时间词；条目 ≥3（编号 ≥2 或短标签 ≥3）；正文块 ≥3。
- **可用版式骨架**：`layout-recipes.md` §4.11（编号 / 短横引导的结论条目）。
- **可用效果族**：标题 fade，条目分批 `fade` / `wipe_l`，每批 ≤4 条（§2，both）；转场
  `fade` / `wipe_u`。
- **不要用什么 + 反例形态**：条目不套表头列结构混成表格；不混入感谢语 / 告别母题；条目不挂
  弹跳类。反例：结论清单被当成表格清单加表头；结尾页的成果条目被误判为结论清单。

### 2.16 GAL-1 图集 / 图墙

- **识别特征**：内容图片（`p:pic`，边长 ≥900000 EMU）≥3；非整页背景媒体；正文块 ≥2。
- **可用版式骨架**：`layout-recipes.md` §4.12（网格 / 行列并置 + 短图注）。
- **可用效果族**：图片分批 `fly_up` / `wipe_l`，每批 ≤3 张，图注同批 fade（§2，both）；
  图集配方 R4（自动换片）/ R14（立体轮播）见 `effect-recipes.md`，effect_first；转场
  `gallery` / `cover_l`（`gallery` 为 p14 高版本转场，兼容档退回 `cover_l`）。
- **不要用什么 + 反例形态**：图片不拉伸填满槽位；同页并置不套跨页轮播骨架；背景媒体页先走 R3
  阻断口径。反例：卡片侧边阴影位图被计入图集图片；越界预览副本被当成图墙条目删除。

### 2.17 CARD-1 并列卡片

- **识别特征**：容器 ≥3（几何面积门：cx ≥1500000、cy ≥400000、cx <11000000），各带文字，
  正文块 ≥4。
- **可用版式骨架**：`layout-recipes.md` §4.1（三栏 / 多栏并列卡片）。
- **可用效果族**：卡片 `fly` / `wipe` / `bounce_up` 分批入场，编号圆牌 `zoom`，卡内文字 fade
  晚 150—450ms；卡片间错开 120—300ms（§3，both；`bounce_up` 弱引擎回退直接出现）；转场
  `cover_l` / `split_h`。批次：`ambient → cards → badge → card_text`。
- **不要用什么 + 反例形态**：跨批卡片的文字不得共用一个组节点；标签条、分隔线、行底不算卡片
  容器。反例：整页文字共用单个组节点，跨批时第一击看到空白卡；元数据小方块被面积门之外的
  计数误当成卡片。

### 2.18 AGD-1 目录

- **识别特征**：目录词命中（目录、大纲、议程、CONTENTS、概览）；正文块 3—12；成行条目 ≥3；
  无主角数字；容器 <7。
- **可用版式骨架**：`layout-recipes.md` §3（序号圆环纵向列表）；成套导航变体见 R17。
- **可用效果族**：圆环逐条 `zoom`，编号 / 章名 / 副标同组错开 60—260ms 淡入（§2 / §3，both）；
  转场 `push_l` / `comb`。
- **不要用什么 + 反例形态**：目录条目不混长段落说明；编号圆环与章名同批；目录改动必须同步
  章节页编号。反例：目录页被当成并列卡片网格；整目录同帧砸出。

### 2.19 END-1 结尾

- **识别特征**：收束结论词命中（总结、三年之后、结尾、展望）；无数字 token；列成果收束条目。
- **可用版式骨架**：`layout-recipes.md` §5（居中大标题 + 收束语 + 署名行）。
- **可用效果族**：收束语分批 fade，收束语最后 `grow_once`（§3，effect_first；兼容档只给 `fade`）；
  转场 `zoom_t` / `fade`；稀疏装饰可整页导入。
- **不要用什么 + 反例形态**：结尾不起新的数据批次；不常驻多条环簇。反例：致谢页带联系方式
  数字被误判为 KPI；成果条目清单被误判为结论清单而漏掉收束母题。

### 2.20 THX-1 致谢页

- **识别特征**：感谢 / 联络词命中（谢谢、感谢、致谢、THANKS、敬请指正、联系方式、邮箱、电话、
  微信、QQ）；无收束结论词；无主角数字。
- **可用版式骨架**：`layout-recipes.md` §5b（致谢语大字 + 联络 / 署名行）。
- **可用效果族**：致谢语 `grow_once` / fade，联络行逐条 fade（§3，effect_first；兼容档退回
  fade）；转场 `zoom_t` / `fade`；稀疏页可整页导入。
- **不要用什么 + 反例形态**：不列成果条目混成结尾页；联络信息不挂数据批次；不常驻多条环簇。
  反例：致谢页出现「三年之后 / 展望」等结论词仍按致谢排；联系方式数字被当成 KPI 主角。

## 3. 路线规则

### 3.1 R3 背景媒体阻断

- **命中条件**：`p:bg` 内存在 `a:blipFill` / `a:blip` 整页照片媒体。
- **推荐处置**：路线判 `block`；先声明烘焙像素处置（replace / keep / block）与基调
  recolor 路径，补齐后再定路线。`check_slide` 先核对媒体与烘焙文字、目标基调与重着色映射。
- **不要用什么 + 反例形态**：`useBgFill` 依赖重、烘焙像素主导的页面不得整页导入；替换背景
  后须确认不残留源媒体、无悬空 rels、Content_Types 同步、`ppt/media` 无孤儿图片。反例：
  背景照片上的像素文字被新背景覆盖后残留半透明轮廓；媒体替换后 rels 悬空导致打开报错。

### 3.2 BUILD-1 原生重建

- **命中条件**：内容结构页（KPI、指标带、趋势图、表格、对比表、组织、时间线、流程、对比、
  案例卡、清单、卡片、图墙、正文），非整页照片背景。
- **推荐处置**：走原生构建；批次结构（角色 + 数量 + 预设族 + 延迟区间）直接喂给 build 脚本；
  预设族按当前引擎档位给：效果优先档可含高版本预设，兼容优先档只给标准 DrawingML 安全族。
- **不要用什么 + 反例形态**：结构必须大改的装饰页不要硬走导入；批次数量与页内元素数不符时
  先拆页，不要把超量形状压进一批。

## 4. 基调与规模约束

- **字数上限**：单块文本 ≤ 60 字；超出先按句拆文本位再编排，不整段挂入场。
- **形状数上限**：单页 ≤ 40 个形状；超出考虑拆页，检查器会在 `cautions` 提示。
- **节点预算**：单页效果节点 ≤ 12、cTn ≤ 60；计划给 `budget.estimated_effects` /
  `estimated_ctn` / `fits`。超预算时按角色切点击批：卡片每批 ≤3 张、表格每行批 ≤4 行、
  节点 / KPI 值 / 步骤每批 ≤3、结论每批 ≤4、图墙每批 ≤3；拆批方案写 `split_plan`
  （`per_batch` + `batch_count`）。
- **行计数口径**：真实 `a:tbl` 按 `a:tr` 行数；非表格按 y 坐标聚类成行（同 y 带容差内
  多段文本归一行），通栏标题与页脚备注不参与行计数，表头单独成行不进滚动批次。
- **卡片配对**：第 i 张容器与其文字同批成对；编号圆牌随卡片 zoom，不单独占效果节点。
- **背景依赖**：页面填充或 `useBgFill` 依赖整页照片媒体时，不得整页导入，先过 R3 阻断口径。
- **深色底**：深色基调不用浅色系配件（浅灰描边、低饱和浅色块）；重着色保留颜色变换节点，
  冲突无确定性消解路径时阻断。
- **反例形态**：深色底上挂浅底卡片而无对比层级；一页内混合多套入场方向；超量内容挤在
  同一批，放映时只有描边在动。

## 5. 保守档口径

- 信号不足或规则重叠：`confidence: low`，页型落到次优保守档（默认并列卡片），批次按最少
  批次方案给，路线优先 `native_rebuild`，不给出高冲击导入建议。
- 保守档是信号不足时的页型 / 批次兜底，与引擎档位正交：`compat` 档在保守档基础上再把预设族
  收窄到安全族；`effect_first` 档的低置信页型同样不推高冲击导入。
- 工具内无法证伪的项（真实放映观感、custGeom 在特定渲染器的包围盒填充行为）不在计划里
  下结论，留到目标机 F5 复核。
