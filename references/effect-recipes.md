# 效果配方库（17 套）

> 本文件从一批已调试完成的动态样稿中拆出可复用配方。每条记录页数规则、素材门槛、图层结构、
> 动画与切换、引擎限制与关键规则；样稿示例文字与占位图不沿用，只抽结构与参数。
> 许可边界见 `source-inventory.md`；动画白名单与节点口径见 `effects-catalog.md`。

## 1. 复现方式分类

| 分类 | 含义 | 处理方式 |
|---|---|---|
| 原生重建 | 几何简单，可用本技能形状封装 + 通用动画从空白搭出近似版 | 按配方参数自建；标注与原件的观感差距 |
| 参考件移植 | 几何、层级或时序由参考件锁定，从零重建会失真 | 持有参考件时复制页，只改文字与图片填充；不强行复刻形状顶点 |
| 高节点密度 | 单页大量形状与动画节点人工调校 | 只改文案、字号、颜色；形状位置层级与时序不动 |

引擎限制：标注 Morph 的配方，其跨页连续变形在 PowerPoint 2019 上被剥离、走 fade 兜底，
仅 365 / 新版 WPS 可能执行；页内动画不受此限制。

## 2. 可原生重建配方

### R1 斜切滑入

- **页数**：2 页。**素材**：1 张 4:3 风景照，不能过暗（黑标题压底图，过暗需改白字）。
- **结构**：第 1 页所有文本框向左移出画布；第 2 页标题落位左侧，斜切平行四边形图片落位右侧。
  底图灰度 + 轻虚化，整幅拉伸；上下可加纯色压条。
- **动画/切换**：标题自左滑入、斜切图自右滑入；第 2 页 Morph 1 秒（L1），单击触发。
- **几何参数**：平行四边形按外框归一化，上边从 0.25w 起、下边到 0.75w 止；
  阴影黑 40%、模糊 4pt、距离 3pt、方向 45°。
- **规则**：斜切图先按槽位比例裁切再压入窄高平行四边形，直接放原图会被拉伸；
  两页配对对象必须同名。

### R2 加载指针

- **页数**：1 页。**素材**：1 张 4:3 深色照片作幻灯片背景。
- **结构**：铺满纯色底压在照片上；标题居左；指针组合（3 矩形 + 1 椭圆）放在 70×70cm
  超画布位置，只露出中段，不要按画布内尺寸修正。
- **动画**：标题淡入 1.5 秒；指针七段变速陀螺旋，角度依次 +270° / −540° / +540° /
  −420° / +300° / −210° / +60°，**累计 0°**，转完回到起点；末段百叶窗退出。
- **规则**：旋转角度必须配平为零，否则每循环一次累积偏移；首段改「在上一动画之后」时，
  组级 delay 与首段 nodeType 要一起改，只改一处不生效。静态预览看不出转动，须 F5 复核。

### R3 纯矢量章节骨架

- **页数**：33 页量级，可按章节删减。**素材**：无照片依赖，仅装饰竖条与小图标。
- **结构**：封面 → 转盘式四章目录 → 前言绿卡 → 各章章节页 + 内容页（编号大数字 /
  评价列表 / 时间轴）→ 收尾感谢。左侧竖排章节名贯穿，右侧内容区；圆形/椭圆作装饰。
- **配色**：深绿 `#3F6B4A`、浅绿 `#C9DCC4`、米白 `#EEF3E8`、灰 `#6B7280`（可按基线替换）。
- **动画**：每页 1–3 个淡入/浮入；页面切换以 Morph 为主（L1）。
- **规则**：版面靠文字撑住，清空文字会退化成白板——要做通用版就换同结构占位文字
  （按字号分标题/小标题/正文），不要留空；绿卡上的文字必须用白色；目录改了必须同步章节页。

### R4 金边弧线（自动换片图集）

- **页数**：19 页量级。**素材**：16 个媒体槽，横竖混排；不足槽位可重复使用同图，
  画幅不符居中裁切，不拉伸；竖槽只放竖图。
- **结构**：白底，深蓝粗弧线从页边切入贯穿；照片放圆形/半圆取景；章节页 200pt 以上超大数字
  配英文副标；正文区大量留白、字少、行距大。
- **动画/切换**：慢速切换 2 秒 + `advTm=2000` 自动换片；仅目录页有 8 个淡入/浮入，其余靠切换推进。
- **规则**：自动换片是节奏核心，改页数时不要顺手关掉；大数字页文本框窄，长文案会破版，需单独放大或缩短。

### R5 暗红塔影（斜切长条）

- **页数**：11 页量级。**素材门槛**：主体图仅限两种——白底原图（白底像素判为背景），
  或已抠好的透明 PNG；暗调满版/带场景背景做不出线稿，边缘白底占比过低直接阻断。
- **结构**：深红底 `#2B0908` + `#4A0E0C` 大圆光晕；主体金色线稿 `#ECCE96`、alpha≈0.85；
  半透明斜切光束（8–10%）+ 金色光点；英文标题字距拉开。
- **长条构成**（最常调部分）：平行四边形 13.8×1.5cm，斜切 adj=18%；下垫同形状外扩约 0.17cm
  纯黑底、80% 不透明透出红底；文字是独立文本框浮在最上层；黑底在长条正下方。
- **动画/切换**：Morph 1.8 秒（L1）；主体从无到有，后段塔位左右互换、长条跟随位移。

## 3. 参考件移植配方

整页移植的前置检查、媒体与主题色处理、文字映射组织和导入后验证见 `import-guide.md`。
依赖媒体分组替换或主题色落位的配方（R6、R7、R8、R10、R12、R13、R14），导入前先跑
inspect 核对媒体槽与主题色；高节点密度页（R16）只改 `a:t` 文本节点，不重建文本框。

### R6 玻璃碎片散开

- **版本**：短版 3 页（1 图 + 标题 + 4 编号）；长版 19 页（玻璃开场 → 目录 → 分段 → 四栏拼贴）。
- **结构**：照片铺满 + 30% 黑遮罩；4 个「图文框」叠在中心、旋转约 44°，只有投影可见；
  中段散开、放大到约 18.4cm 各自旋转；末段落成一行 5cm 方块。
- **关键机制**：玻璃框用**幻灯片背景填充**（照片在 `p:bg`，框透出背景本身），视觉上只剩投影；
  给框填图片会变成一堆彩色菱形。
- **动画/切换**：Morph 2 秒；标题 96pt 浮现，目录 72pt + 编号 60pt。
- **规则**：行距 90%；两段标题用段内换行 `a:br`，不要多出行；编号锚点比几何中心低约 15px 需补偿。

### R7 哲学字动（巨型字母穿插图集）

- **页数**：图数 ×2+2；推荐 4–5 张图。**素材**：多张横/竖幅照片，按画幅比例匹配槽位，不按口述顺序套。
- **结构**：巨型字母页与整页照片页交替；字母在页间位移重排；可配跨页音频。
- **动画/切换**：`advClick=0` + `advTm` 0.5–2 秒自动换片；Morph 0.6–6 秒。
- **移植约束**：约 120 个对象 + 5 张分组蒙版照片，从零重建必然失真；以参考页几何为模板只换素材。
- **规则**：音频跨幻灯片播放需 `numSld="999"`，只写 autoplay 会播完本页就停；
  删页要同步清 sldIdLst、presentation rels、slide rels、备注页、Content_Types 五处，缺一报修复。

### R8 扇形展开

- **页数**：2 页。**素材**：1 张约 1.77 横构图照片。
- **结构**：12 片 blockArc 扇片分两组——右侧大扇 6 片（约 38.44×36.46cm）、左上小扇 6 片
  （约 20.68×19.51cm）；第 1 页收拢在底部偏中，第 2 页展开铺满右侧；竖排标题在画面外滑入中央。
- **动画/切换**：Morph 2 秒；扇片阴影 24 处 outerShdw，模糊约 10pt，不透明度分 90% / 40% 两档。
- **规则**：两页共用一个媒体，替换一次即可；阴影是形状自带的，弱了就改 blurRad/alpha，不要新增；
  竖排文本 `bodyPr` 带 `vert="eaVert"`，改字数要重算框高。

### R9 三段上滚

- **页数**：3 页共用 1 张底图。**素材**：1 张照片。
- **结构**：标题 + 三段正文逐页上滚；大号章节号左侧出血；弧形装饰线用 custGeom + 背景填充，
  透出未被压暗的原图，形成一片边缘只有描边的亮窗（设计如此，不要改成无填充）；50% 黑蒙版统一色调。
- **机制**：「滚动」不是页内动画，是三页里同一批文本框的 y 坐标不同；改文案长度后按实际行高重算三页 y。
- **出画规则**：待出现段落整体落在页高之下（y ≥ 页高）；已滚走段落整体退到 y+h ≤ 0；
  不许露出一行一角。画布内段落压标题是原设计，退场段落乱入不是。
- **动画/切换**：Morph 1.5 秒。**规则**：删文本框必须先清对应 timing 引用，否则文件报损坏。

### R10 环形开场刀片阵

- **页数**：25 页量级（开场 8 页 + 内容 17 页）。**素材**：开场共用 1 张 1200×900 图；整套 13 张媒体逐槽替换。
- **结构**：24 片背景填充白刀片 + 24 片黑片，贝塞尔圆角楔形（每片 8 控制点）；
  层级：背景 → 黑幕矩形 → 白刀片 → 黑刀片；其后圆形取景、四字 2×2 散排、目录与内容模板。
- **动画**：每片 1 个缩放进入（presetID=23，宽高 anim），48 个效果；延迟步长 = 单次时长 140ms，匀速。
- **规则**：刀片顶点由手工调校，禁止脚本按四点+圆心重算（会退化成退化形状、页面变黑）；
  黑片必须与白片同源同位置，任何偏移都会露边；静态预览开场是黑屏，必须 F5 复核。

### R11 中式滑转（多图版）

- **页数**：图数 a（2–9）→ a+1 页（封面 + a 图页）。**素材**：竖幅约 0.81 画幅。
- **结构**：同尺寸斜切面板阵列；第 n 页层级自上而下为文本组合、纯色小色块、标题、正文、
  图片填充色块；第 n+1 页整体顺移一位。
- **规则**：按对象名严格填图/上色（图 K ← 第 K 张图，色 K ← 第 K 号颜色）；纯色块强制 solidFill；
  背景色与该页纯色块同源；相邻页左右镜像；奇数末页色左字左/图右，偶数末页保持模板原样；
  复制页后重编形状名为目标索引。

### R12 六边形双层错位

- **页数**：固定 6 页。**素材**：1–4 张，不足可复用；满页底图在 `p:bg`。
- **结构**：外六边形白线无填充 + 内六边形图片填充；主/副标题左右交替落位。
- **规则**：内外六边形尺寸与旋转角都不同，双层错位是有意设计，不要强行对齐或统一角度；
  每页只有内六边形一个图片填充对象；背景换图要同步替换，否则与六边形内图割裂。切换全页 Morph。

### R13 模糊遮罩大字页

- **页数**：5 页。**素材**：1 张横图（可 5 页共用，也可每页一张）。
- **帧序列**：P1 四个文本框在画布上方负坐标（隐藏态）→ P2 落到海报式大字阶梯（72/36/32/28pt）
  → P3 与 P2 完全相同（停留帧，必不可少，否则 Morph 一闪而过）→ P4 六边形在画布外准备推入
  → P5 六边形到位、文字整体左移出画、主标题变竖排。
- **模糊**：半径 50、亮度 −10，用图片处理预烘焙；演示软件艺术效果存为不可解析的介质格式，不要依赖。
- **规则**：文字入场靠 Morph 位移，不要再叠加页内动画，两套时间轴打架；
  媒体分清晰层 / 模糊层 / 切片层三组，按页分组替换，只换一张会串旧图；同段文字的大小副本必须移出画布。

### R14 立体图片轮播

- **页数**：N+1 页（N 张图，3–10）。**素材**：横图为主，兼容 1.78 / 1.6 / 1.33 画幅。
- **结构**：顶部标签条（激活项高亮拉长）+ 主体大图 + 左下缩略图；左侧标题/副标/正文。
- **图位规则**：P1 开场图 1+图 2 重叠；Pk（k≥1）A=图 k（画布内大图）、B=图 k+1（内小图）、
  C=图 k+2（画布外左）、D=图 k−1（画布外右）；越界图位移出画布（y=−50cm）。
- **规则**：标签只能隐藏不能新增，减到 N 个后等距排布，多余标签移出画布；高亮块居中对齐激活编号；
  每段文字有大小两份形状，小副本移出画布（y=−40cm）隐藏，否则出现重影。切换靠 Morph 推拉。

### R15 多边形巡游

- **页数**：1 页。**素材**：1 张 1.78 背景图。
- **结构**：满页图片背景（亮度调亮、拉伸铺满）；主体为 965 点任意多边形，80×80cm 超画布，
  仅中间一段落在可视区；标题 72pt 加粗、副标题 60pt 加粗。
- **动画**：五段折线 animMotion（相对坐标）+ 自转 360° + 标题副标题淡入淡出；
  时长 1000 / 1500 / 2500 / 3000 / 4000ms 分段。
- **规则**：路径是相对坐标，改形状尺寸会破坏巡游轨迹；只换背景图与文字，形状与动画不动。

### R16 扫光阵列（高节点密度）

- **页数**：1 页。**素材**：无照片依赖。
- **结构**：31 个形状、99 个动画节点（fade / wipe / 位移 / 缩放混排）；梯形与组合扫光 +
  多段文字按序出现。
- **允许改**：文字内容、字号、颜色。**禁止改**：形状、位置、尺寸、层级、动画时序。
- **规则**：定宽文本框，字号变大或字数变多都会换行挤乱落点；同字叠放的多个文本框要一起改；
  只改 `a:t` 文本节点，不重建文本框（会丢动画绑定）；改完必须 F5 确认无回行、无遮挡。

### R17 双轴导航栏

- **页数**：章节数 × 子页数（样例 5×4=20 页）。**素材**：0–2 张配图。
- **结构**：顶栏管子页、左栏管章节；当前章节项与当前子页标签变浅蓝胶囊，其余保持原色。
- **允许改**：章节中英文名、子页标签、整体字体、字号、整套配色。
- **禁止改**：形状几何与位置——高亮胶囊与文字是对齐关系，一动就错位。
- **变体**：同骨架有偏学术风版本；顶部导航与左侧导航两种版式可按内容选。

## 4. 跨配方通用规则

### 4.1 Morph 配对与枚举

- 前后两页对应对象同名、同类型、数量一致；需要跨类型配对（圆变方、图变图、字变字）时，
  对象名以 `!!` 开头强制按同名匹配。
- `p159:morph` 的 `option` 只能是 `byObject`；写 `object` 不是合法枚举，文件会被判损坏，
  且库解析工具不报错，必须用演示软件真开一次验收。
- Morph 位移的对象不要再叠加页内动画；配对不成立时不要写 morph 转场。

### 4.2 背景填充形状

- 「幻灯片背景填充」形状透出的是 `p:bg` 背景本身：玻璃框、弧形亮窗、取景窗都用此机制；
  改成无填充会丢掉透出效果。形状可带描边与阴影。
- 整页背景图在 `p:bg/a:blipFill/a:blip`；形状/图片取景在各自 `sp`/`pic` 下的 blipFill。

### 4.3 画布外出画

- 准备帧、下一段推入的装饰/面板先放画布外（负坐标或 y=−50cm），目标帧再推入；这些元素不能删。
- 该退场的文本框必须整体在画布外，逐框算 y 与 y+h 和画布高度的关系，不许露一行一角。

### 4.4 删形状与 timing

- 删掉挂有动画绑定的形状前，先整块删除对应 `p:timing` 引用；只删形状留 timing，文件会报损坏，
  而解析工具照样能打开，容易误判成媒体或压缩包问题。
- 改文案只改 `a:t` 文本节点，不动 `rPr` 字号字体与 `p:timing`；重建文本框会丢失动画绑定。

### 4.5 媒体分组替换

- 一组配方的媒体常分清晰层 / 模糊层 / 切片层，按页分组；换图按名单整体替换，只换主图会串旧图。
- 照片先比画幅比例再决定槽位，比例不符居中裁切，不按页序硬套、不拉伸。

### 4.6 图片预处理

- 演示软件的艺术效果（模糊、饱和度）存为不可解析的介质格式；需要虚化/压暗时用图片处理预烘焙进位图。
- 亮度/模糊半径以配方记录为准；换亮底图后亮窗对比过强时，调高蒙版透明度，不要动背景填充。

### 4.7 占位文字与字色

- 占位按字号分档：≥28pt 标题档，其余正文档；字色随页面平均明暗切换，暗底白字、浅底深字。
- 定宽文本框关闭自动换行，避免短文案折行压版；英文换词优先首字母大写 + 字号缩 4–8pt，仍换行才换短词。

### 4.8 字体与竖排

- 缺字体时中文回退系统黑体、西文回退默认衬线；锁定字形需使用端预装同档字体。
- 竖排文本 `bodyPr` 带 `vert="eaVert"`；改字数后竖排高度要重新量框。

### 4.9 自动换片

- `transition(slide, kind, adv_ms=2000, on_click=False)` 写自动换片；自动换片节奏是图集类配方的核心，
  不要在改页数时顺手关闭。需要自动翻页时在页面换片时间上设置，不靠动画时长硬凑。

### 4.10 路径动画

- 直线往返：`(name, "path", delay, dur, dx, dy)`；
  折线/多段巡游：`(name, "path", delay, dur, 0, 0, "M 0 0 L x y L x y …")`，坐标为相对比例。
