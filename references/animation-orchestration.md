# 动画编排三段与容器—文字配对矩阵

> 书脊级规则：所有页面动效按「环境基线 → 分批入场 → 容器—文字配对」三段编排；
> 配对判定口径与 `scripts/pairing_check.py` 一致。每条规则给判定条件与反例形态，
> 不按事故记录叙述。本章规则与引擎族无关，effect_first 与 compat 引擎族都要守。

## 1. 编排三段

### 1.1 第一段：环境动效基线

- 每页至少一个常驻环境动效：环自转或光点路径往返，进页即播，
  `repeatCount="indefinite"`，不随点击批次退出。
- 关键数字配一次 `grow` 回弹；强调只落在当前章节、关键数字、核心圆环上，不满页闪烁。
- 判定条件：timing 中存在 `emph`/`path` 类常驻节点且重复计数为 indefinite；
  无任何常驻节点的页面判基线缺失。
- 反例形态：整页元素全是一次性入场，放映停住后画面完全静止；数字出现后无回弹，
  重点读不出来。

### 1.2 第二段：分批入场

- 一页 3—6 批；同批元素同时开始，先后靠各自 `delay` 错开 120—300ms，
  时长 400—800ms。
- 页内换批用「旧退出 + 新入场」，不在同帧把下一批铺满。
- 方向铺开：标题淡入、卡片上滑、分隔线擦除、装饰自转，不在一页里全用同一种入场。
- 判定条件：批次对应 mainSeq 外层 `p:par`；批内 `withEffect` 节点的 delay 逐级错开；
  换批页面能找到成对的 exit 与 re-entrance。
- 反例形态：一批内所有元素同帧 fade 铺满；相邻两批没有退出节点，内容叠在一起。

### 1.3 第三段：容器—文字配对

- 任何带容器（rect / roundRect / 胶囊 / 行底 / 卡片）的内容块，容器入场必须与
  容器内文字同批绑定。
- 文字用 fade，晚于容器 150—450ms，不跟位移；退出时文字先消失、容器后走
  （容器晚 100—150ms）。
- 强调（grow / blink）绑数字或文字本身，不绑容器。
- 多张卡片的文字必须按批拆组，不共用一个组节点；共用组节点时单点延迟满足不了多张，
  第一击会看到空白卡，跨批共用判 `shared_group` FAIL。
- 节点预算单页 cTn ≤ 60；预算不够时先砍页头标题滑入，不留孤儿文字。

## 2. 配对矩阵

| 元素角色 | 批次归属 | 入场预设族 | 相对延迟 | 位移 | 退出 | 强调绑定 |
|---|---|---|---|---|---|---|
| 容器卡片 | 随所在内容批 | wipe / zoom / fly | 基准 0 | 可带位移 | 晚文字 100—150ms | 不绑 grow / blink |
| 卡片文字 | 与容器同批 | fade | +150—450ms | 无 | 先于容器退出 | grow / blink 绑数字或文字 |
| 环境环 / 光点 | 第一批自动播 | spin / path | 0 | 路径往返 | 常驻不退出 | — |
| 页头标题 / 分隔线 | 第一批 | fade / wipe | 0—120ms | 少量 | — | — |
| 轮换条（旧退出 + 新入场） | 独立生命周期 | entr → exit → re-entrance | 按条带节奏 | 按条带预设 | 自身成对退出再入场 | — |

## 3. 判定条件（检查器口径）

1. **同批**：容器与文字的入场效果同属 mainSeq 同一个外层批次 par；跨批判 FAIL。
2. **延迟差**：文字入场延迟 − 容器入场延迟 ∈ [150, 450]ms；负值判 FAIL。
3. **fade-only**：文字入场不含 `ppt_x` / `ppt_y` 位移动画、不含 `animMotion`
   路径、不含非 fade 的 `animEffect`；出现位移类行为判 FAIL。
4. **退出顺序**：两侧都有退出时，容器退出延迟 − 文字退出延迟 ∈ [100, 150]ms；
   只挂单侧退出记 WARN。
5. **孤儿文字**：容器有入场动画而其内部文字零节点（无入场 / 强调 / 退出绑定），
   计入孤儿容器计数。
6. **目标与预算**：每个 `spTgt` 的 spid 命中真实形状 id；悬空目标判 FAIL；
   单页 cTn 超出 `--max-ctn`（默认 60）判 FAIL。

识别边界：容器归属按几何包含判定，重叠卡片可能误归属；检查器输出的配对明细需人工
复核一层。离线环境只能做结构核对，不能代替目标机 F5 放映观感复核。

## 4. 反例形态（一眼识别）

- **容器有动画、文字零节点**：卡片 wipe / zoom 进场，框内一直空白；文字在另一批，
  或根本没挂节点。检查器表现为孤儿容器计数 +1。
- **整页文字共用单个组节点，跨批空白卡**：一个组节点挂一个 delay，第一批点下去
  只有先出的卡片有字，后出的卡片文字还压在组里。检查器表现为同一文字组覆盖不同
  批次的容器，`shared_group` 判 FAIL。
- **文字跟容器一起位移，两层打架**：文字带 `ppt_y`（或 `ppt_x`）飞入，与容器位移
  叠加，文字漂移出框。检查器表现为 `fade_only` 判 FAIL。
- **只挂 fade 同帧铺满**：一批内所有元素同时淡入，无常驻环境动效，放映停住后只剩
  描边在动。编排上缺第一段基线，批次内无 delay 错开。

## 5. 检查器

```
python3 scripts/pairing_check.py <deck.pptx> [--min-gap 150] [--max-gap 450]
        [--max-ctn 60] [--json OUT] [--md OUT]
python3 scripts/pairing_check.py --selftest
```

退出码：0=全部 PASS；1=存在 FAIL；2=输入错误或包不可读。输出逐对明细
（容器名 / 文字组名 / 两侧批次与延迟 / 差值 / 判定）与逐页汇总（效果数、cTn、
转场预设、advTm、悬空目标）。
