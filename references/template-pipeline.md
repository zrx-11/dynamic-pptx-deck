# 成品页复用流水线（默认路线）

> 默认路线：**检索成品页资产 → 整页导入 → 只替换文案 / 数字 / 配色 / 图片 → 叠加原生动画**。
> 自绘版式仅在资产索引无匹配页时作为兜底分支。本文件只给工序与纪律；适配检查、
> 导入接口、动画配额、校验报告的细则分别引用 `import-guide.md`、`audit-all.md`、
> `animation-orchestration.md`，不重复展开。

## 1. 工序总览（八步四道闸）

| 步 | 动作 | 闸 / 产出表 | 细则引用 |
|---|---|---|---|
| 0 | 整理内容大纲，声明交付档位；不编造事实，缺失信息用【】占位 | — | `delivery-tiers.md` 第 1 节 |
| ① 选页 | 只从角色适配表 `role-fit.json` 里 fit 通过的候选选，记录 `source_id` | `role-fit.json` | 本文第 2 节 |
| ② **选页闸** | 候选页不得带摄影背景 / 锁定大图 / 烘焙文字；帽条短槽容量不足的直接排除 | 不通过即换候选 | 本文第 2.1 节 |
| ③ 整页导入 | 适配检查先行，`import` / `adapt` 写入目标包 | — | `import-guide.md` 第 4、11 节 |

## 2. 选页判据

- **按角色查**：在 `layout-assets.md` 的角色分组（机读版取 JSON 记录 `role`）里找目标页型；
  索引可换文案角色 8 个（`cover`、`section_transition`、`kpi`、`process`、
  `card_grid`、`agenda`、`thanks`、`gallery`）；其余 12 个按可换文案口径为缺口角色
  （`case_card`、`quote` 已有成品页，但被烘焙 / 背景填充阻断，暂不可换文案）。
- **记录来源**：选定候选后记下索引 `id`（即 `source_id`，形如 `ref-007-p2`）、`deck`
  相对路径、页码、`tone` 基调、`slots` / `capacity_total` 容量、`baked_text`、
  `usebgfill`、`anim` 动画节点数，供导入与配额核对使用。
- **同族优先**：基调（dark / light）、主色系、画幅与目标稿一致；基调冲突且无 recolor
  路径的页面不选。
- **兜底分支**：缺口角色，或同角色无可换文案页时，转 `dynamic_deck.py` 原生自绘；
  版式骨架与效果族候选查 `asset-index.md` / `asset-index.json`，配色基线见
  `layout-recipes.md`。

### 2.1 选页闸排除条件

- **背景与图片**：带摄影背景（整页照片 / 全幅位图背景）、锁定大图（图片构成版式主体，
  `locked_images` 为真）的页，不进入改动文案候选。
- **烘焙与背景填充**：`baked_text.state = yes`、`usebgfill = true` 的页排除出换文案
  流程；`suspect` 需人工核对后再定。
- **短槽容量**：帽条 / 标题等短槽对照实测容量表放不下目标文案的候选，直接排除，
  不进入导入。
- 闸口不通过即换下一个候选；全角色无可用候选时转兜底自绘分支。

## 3. 导入参数

- 快照先行：`inspect --src X.pptx [--index N]` 读文本槽、媒体、主题色、关系类型与背景线索。
- 适配报告：`check --src X.pptx [--index N] [--profile profile.json] [--target-texts texts.json]`，
  按文本槽位、基调配色、媒体背景、烘焙像素四维度出报告；报告未通过的页面不导入、不适配。
- 整页导入：`import --src X.pptx --index N --dst D.pptx [--out O.pptx] [--map map.json] [--by-name]`。
- 带消解动作的适配写入：`adapt --src X.pptx [--index N] --dst D.pptx --profile profile.json
  [--out O.pptx] [--map map.json] [--recolor recolor.json] [--media media.json] [--strict]`；
  未消解冲突在写入前阻断。
- 导入处理范围（slide part / rels / 媒体去重 / layout 重指 / 备注丢弃）见 `import-guide.md` 第 5 节。

## 4. 容量闸：实测换文案纪律

- **只改文本与色值**：导入后只替换 `a:t` 文本串、按 `recolor_map` 改色、按 `media_map`
  换图；**禁止重排坐标、禁止改几何层级、禁止重建文本框**（重建会丢失动画绑定）。
- **实测而非估算**：逐槽用真实字体实测文本宽高，结果记入 `slot-capacity.json`；索引
  `slots` / `capacity_total` 与 `estimate_slot` 仅为离线预判，落位以实测为准。
- **超限处理**：用 `scripts/textfit.py` 按「缩字号至下限 → 加高容器 → 报需减字」三段顺序
  处理（细则见 `layout-tools.md` 第 2 节）。缩字号允许但**下限为 `--min-pt`（默认 10 pt）**，
  且每次缩字号必须登记在原槽记录里；**禁止改宽度、禁止移动水平位置、禁止重建文本框**。
  三段都不能收敛时，退回换短文案或换候选页，不得静默压字。
- **框空同样不合格**：`textfit` 返回 `empty_frame` 的槽必须按它给的字数区间补足，或按
  内容框闸删除形状；不得把「装得下」当作「填满了」。
- **事实核对**：导入页上的事实性数字与结论，文字替换后仍需回素材 / facts 清单核对；
  样稿示例文字、占位图一律不沿用。

### 4.1 槽位自适应边界（flex_slots 口径）

> 与 `layout-assets.md` 附录「槽位自适应边界」同一份常量口径；坐标换算：原画布
> 1280×720 px（13.333in 宽幻灯片），1 px = 9525 EMU。

1. **槽位身份可互换**：文框与图形框在视觉层级不变时可互换承载；文本优先文框，整块图优先图形框。
2. **相邻槽可合并**：文案字数超单槽容量 1.5 倍以上时，允许合并同行 / 同列相邻两槽；合并宽度取两槽外框并集，不得越出内容区。
3. **可放大**：向外扩展不得超过原尺寸 25%，且不得与其它槽重叠。
4. **可下移避让**：与标题 / 装饰冲突时整体下移，下移量以冲突消除为准，上限为内容区高度的 15%。
5. **标题槽**：宽 380–1160 px（折算 3,619,500–11,047,800 EMU），高 56 px 单行 / 96 px 两行；顶部对齐，两行时不得压行距。
6. **横向导航条**：厚度 64–72 px 可变，宽度固定。
7. **内容槽一律不得移出画布。**

## 5. 内容框闸：填满判定

- **内容框定义**：有填充或边框、面积 ≥1.5 平方英寸、非纯装饰的形状 / 文本框；装饰环、
  光点、连线、背景色块不计入。
- **判定**：逐框测算墨块覆盖率；覆盖率 **< 25%**，或完全无文字，即判不合格。整页导入
  会把源页所有槽位一并带入，只填一部分会留下「看起来是内容区、里面却空着」的框，按
  不合格项处理。
- **处置顺序**：
  1. 补实事文案：每框 2–4 行，不跨框重复同一段；
  2. 图位改数据胶囊：数字 + 短语；
  3. 确实无内容：删除形状并回到构图复核，不留空框。
- **产出**：`empty-area-report.json`，逐框记录覆盖率、是否无文字与处置结果；未归零
  （仍有不合格框）不得交付。
- **与容量闸分工**：容量闸管「装不装得下」（宽高实测），内容框闸管「填没填满」
  （覆盖率与空框）；两道闸分别出表，不互相替代。

## 6. 动画配额与挂载位置

- 每页配额（写死，`audit_all.py` 按此判）：
  - 可感知运动对象 **≥3**（位移 / 缩放 / 旋转 / 擦除 / 路径 / fly / zoom 计入；
    fade / opacity / appear 不计；退出类不充数）；
  - 持续循环 **≥1**（环自转或光点路径巡游，无限重复）；
  - 效果总数 **≤12**，cTn **≤60**。
- 挂载位置：页内动效挂在非配对对象上（装饰环、光点、连线、数字、标题下划线、卡片内文字等）；
  Morph 配对对象页内只允许 fade / opacity，不得挂位置类页内动画。
- 编排三段（环境动效基线 → 分批入场 → 容器—文字配对）与配对矩阵见
  `animation-orchestration.md`；效果白名单与弃用清单见 `effects-catalog.md`。
- 索引页自带的 `anim` 节点数只作参考；导入后仍需按本稿配额补齐或收敛。

## 7. 成稿闸：重叠检测

- 成稿交付前跑程序化重叠检测，两类命中：
  - **文本框互压**：相邻文本框 / 容器包围盒相交压盖；
  - **文字超出框高**：实测文本高超出框高或溢出文本框边界。
- 命中项逐页逐槽记入 `overlap-report.json`；任一命中即不得交付，退回容量闸、内容框闸
  或选页闸修正后重检。
- 成稿闸独立于 `audit_all`：合并校验不做版面重叠与空框检测，这类问题不靠动画配额或
  配对检查兜底。

## 8. 合并校验与导出审查

```bash
python3 scripts/audit_all.py <deck.pptx> --manifest deck-manifest.json --tier fidelity_first
```

- 一次调用合并结构、配对、可编辑性、schema 深扫、动效配额五类检查；不要分别跑
  `dynamic_deck.py check`、`pairing_check.py`、`editability_check.py`、`effect_router.py`
  四遍。单独调这些脚本仅用于排障定位，关系见 `audit-all.md` 第 7 节。
- 建稿中途可用 `--fast` 跳过 schema 深扫快速回环；**交付前必须全量跑一次**（不加 `--fast`）。
- 校验通过后，**一次**用 LibreOffice headless 导出 PDF / 静帧核对静态版式与文本落位；
  LO 不解释动画，不能据此判断动效是否生效。
- 只对 audit 报错的页面看图：不达标页（配额缺失）、阻断页（可编辑性 / 结构化源）、
  Morph 冲突页；问题页控制在少量范围内，修完重跑一次 `audit_all.py` 复核。
- 移植类与高版本效果在目标放映软件 F5 复核后再标「实测」；未复测前标注「未复测」。

## 9. 四张工作表

| 表 | 用途 | 产出时机 |
|---|---|---|
| `role-fit.json` | 角色适配与判据：按页角色列出 fit 通过 / 不通过的候选页及判定依据（基调、色系、画幅、槽位结构）；选页只从 fit 通过项取 | 选页前建一次 |
| `slot-capacity.json` | 实测容量：逐槽记录真实字体下的文本宽高实测值与容量上限；替换文案前以本表为准，索引 `capacity` 仅为估算；管「装不装得下」 | 换文案前建一次 |
| `empty-area-report.json` | 内容框填满结果：逐框记录墨块覆盖率、是否无文字与处置结果；未归零即不得交付；管「填没填满」 | 内容框闸检测时建一次 |
| `overlap-report.json` | 成稿重叠结果：成稿闸检测输出，逐页 / 逐槽记录文本框互压与文字超出框高命中项；有命中即不得交付 | 成稿检测时建一次 |

- **分工**：四张表一次性建好，后续工序只查表引用，不重复测量；表随结构化源归档，
  供页级重生成复核。

## 10. 许可声明纪律

- 成品页资产属第三方素材：个人学习与校内汇报场景可用；公开放映或商业交付前，必须在
  交付说明 / README 中声明资产来源与许可范围，未获授权则退回自绘分支。
- 索引只记录路径与结构特征，**不打包资产本体**（pptx / 静帧 / svg 均留在参考件目录）。
- 许可分级与素材使用纪律另见 `source-inventory.md` 第 1、2 节。

公开 / 商业交付随稿附声明模板：

```text
本稿复用的第三方成品页资产：来源包 <pack / deck>，页 <source_id>；
许可范围：<个人学习 / 校内汇报 / 已获公开或商用授权>。
未获公开或商业使用授权的资产，本稿不用于公开放映与商业交付。
```
