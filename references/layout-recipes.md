## 1. 配色与字体纪律

五套可切换基线，同稿内不混用色族；按题材与受众选一套贯穿全稿。

**A. 浅色商务基线（通用汇报主流，封面多为浅色/照片底）**

- 背景：白 / 极浅冷灰 `#F5F8FB`；内容卡片纯白，配极细浅灰边或 1px 主色顶/左边缘。
- 主色：商务蓝 `#0070C0`，亮青 `#00B0F0`；辅助：绿 `#73B829`、红 `#C00000`（仅风险/强调）、
  金 `#FFC000`、青碧 `#01ACBE`。
- 文字：深墨 `#1F2D3D` 主文，灰 `#5B6B7B` 副文；不用近白文字压浅底。
- 高频形状母题：rect / roundRect / ellipse / line 为主，chevron、donut、hexagon、diamond、
  triangle、arc、blockArc、homePlate 作编号与流程点缀。
- 字体：标题粗书体，正文黑体 Regular，强调 Bold。

**B. 深色科技基线（数据/产品/技术题材备用）**

- 背景：深海军蓝渐变；卡片用比背景亮一档的深蓝。
- 主色：青蓝 / 湖蓝圆环与线条；强调色：暖金。文字近白，副文浅蓝灰。

**C. 红金商务**：主红 `#C00000`、深红 `#901102`、肤金 `#DDAF86/#E9B788`、金 `#FFC000`、
藏青 `#25314B`；形状母题 plaque 牌匾、star5、round2SameRect、hexagon、roundRect 筹码。

**D. 紫夜梦幻**：主紫 `#504F9F`、深紫 `#7030A0`、金 `#EEC988/#CB954D`、蓝 `#5A83DE`；
形状母题 trapezoid、triangle、ellipse、圆环十字准星。

**E. 深绿山林**：主色深青碧 `#437477`、浅青碧 `#549195`、灰紫中性 `#6E6272`、
深炭 `#42413D`；形状母题 donut 缺口圆环、rtTriangle、parallelogram、roundRect 双段 chip。

### 1b. 批量样稿拆解结论（2026-11 抽样渲染 + 全量 XML 统计）

- **封面**：大粗体中文标题 + 英文小标（CONTENTS / 主题英文）+ 短色线；
  斜向蓝/彩色带或丝带横贯；圆形徽章、剪影/图标等位图底图（无授权素材时重画为几何形）；
  标题常压在照片或浅渐变上。
- **目录**：01–04 圆形/圆角编号徽章 + 章名 + 一句副标；chevron 或彩色筹码行；
  编号圆环与章名左右排列。
- **内容页**：页头 = 主色小 kicker（PART 01）+ 粗体中文标题 + 短主色横线；
  白色圆角卡片带顶部色条或左侧竖边；椭圆/圆角编号 chip；连线、箭头、时间线圆点；
  页脚细线 + 页码/小圆点。
- **配色频次 Top**：`#0070C0` 蓝、`#C00000` 红、`#FFC000` 金、`#00B0F0` 青、
  `#73B829` 绿、`#01ACBE` 青碧；黑白为文字色不计入主色。
- **动画观察**：path 类预设用量最大；zoom 23/16 旧版预设带真实 w/h 缩放节点，
  等价模块 `zoom`；部分动态样稿转场写 p159:morph，按 L1 配对规则处理。

### 1c. 可复用版式母题

- **全屏照片底 + 环簇叠加**：封面整幅照片，同心环 + 径向辐条（或十字准星）压在照片上，
  中心圆盘裁切局部照片；白色粗体标题直接压图，配英文小标。无授权照片时用纯色渐变底。
- **信息筹码**：主色 roundRect 小标签 + 白字（作者 / 单位 / 角色 / 日期 / 组别），
  成行或成对排列。
- **章节数字圆环**：圆环内放大写中文数字（壹/贰/叁/肆），环下配章名；替代阿拉伯数字徽章。
- **六边形雷达卡**：hexagon 顶点标注维度，白底卡 + 主色描边，用于测评/能力展示。
- **缺口圆环目录徽章**：donut 带径向 tick 缺口，环内两位数编号，环下章名。
- **标签+值双段 chip**：主色标签框 + 白色值框成对排列（信息行：标签 / 取值）。
- **四象限卡**：照片或浅底上四张象限卡，大字母（S/W/O/T 等）作视觉锚点。
- **斜向分栏封面**：白底与配图用斜向色带对半切开，粗体标题压在分栏交界。

## 2. 封面母题：左侧信息块 + 右侧转盘

结构：

- 左侧自上而下：单位/角色小字 → 大标题 → 副标题 → 短分隔线 → 两列信息行
  （作者 / 单位 / 角色 / 日期等，按素材取舍）→ 底部一句话定位占位。
- 右侧：多层同心转盘——静态细环 + 2–3 段不同半径/角度/颜色的可旋转分弧 + 十字细线
  + 中心轴点；半径由外向内递减，弧长与厚度同步递减。
- 动效：转盘分弧进页即自动自转（正反向、不同周期）；标题淡入，分隔线擦除，信息行逐条淡入。

## 3. 目录：序号圆环纵向列表

- 左侧标题「目录」+ 英文小标 + 短线；右侧或主区纵向 3–5 行。
- 每行：空心圆环内放两位数编号 → 章节名（粗体）→ 副标题（小字浅灰）。
- 行间距均匀；可在页尾或对角放一组缓慢自转的装饰环簇。
- 动效：圆环逐条出现，编号/章名/副标同组内错开 60–260ms 淡入。

## 4. 内容页骨架

### 4.1 三栏并列卡片（并列选项 / 并列维度 / 分点论述）

- 三张等宽圆角卡片横排，间距一致；卡片内：小标题 + 要点列表。
- 顶部页标题 + 一句引导语；卡片可配编号或小图标位。
- 动效：标题淡入；卡片依次上滑（或从两侧飞入）；要点随卡片后淡入。

### 4.2 双栏对照（优劣 / 正反 / 问题与对策）

- 左右两栏，栏头用不同色标（主色 / 暖金或灰）；每栏 3 条以内要点。
- 对照页可做成「问题卡 → 对策卡」成对结构，左问题右对策。
- 动效：左栏先入、右栏后入；同栏要点逐条淡入。

### 4.3 横向时间线（阶段推进 / 项目历程 / 路线规划）

- 一条横线贯穿，节点圆点在线上；节点上方或下方放阶段名、时间、事项、说明。
- 节点用主色，当前/重点节点用强调色。
- 动效：横线擦除展开，节点与标签依次出现；重点阶段可配轻微放大强调。

### 4.4 数据表格（计划安排 / 对照清单 / 条目罗列）

- 表头按素材列字段；行高均匀，细线分隔，隔行浅底。
- 表下可放一行串联结论（箭头串联要点）。
- 动效：表头淡入，行逐条擦除或上滑；避免整表一次性砸出。

### 4.5 Q&A 卡片（访谈 / 答疑 / 问答拆解）

- 顶部对象/主题信息条；下方 2–3 组问答卡：Q 标签 + 问题，A 标签 + 回答。
- 问答分栏或上下堆叠；回答文字不超过 4 行，长句拆要点。
- 动效：信息条淡入；每组问答一批，Q 先于 A。

### 4.6 KPI / 数字带（可选）

- 并列大数字 + 小字注释；数字用粗体大字，注释浅灰。
- 素材无真实统计数字时不用 KPI 带，禁止编造数字。

## 5. 章节过渡页与结尾页

- 章节过渡：大号章节编号 + 章名 + 一句引导语；背景可放低透明度环簇或渐变。
- 结尾：居中大标题（致谢/总结）+ 3 句收束语 + 底部署名行（单位 · 角色 · 作者/日期）。
- 动效：过渡页标题淡入 + 环簇自转；结尾标题放大淡入，收束语逐条淡入。

## 6. 终端风装饰手法

从深色技术风原生成片反查吸收：

- 深色底上的多层同心环、短弧段、径向细线、刻度小点、中心轴点。
- 环簇分弧正反向不同周期自转；小点做相对路径往返漂移（ambient motion）。
- 标签用等宽感小字、低透明度；强调只落在当前章节环上。
- 行为节点构成参考：set 可见性为主，配合 animEffect、anim 位移、animMotion 路径；
  内嵌视频不搬。

## 7. 环境动效母题

- **自转环**：分弧/扇面包进同心组合体，锁定轴心（见 effects-catalog 第 8 节）。
- **漂浮点**：小圆点用 path 相对路径往返漂移，周期 6–12s，autoRev。
- **呼吸强调**：关键对象 grow 放大回弹；当前章节环 blink 闪烁一次即可，不长闪。
- **分隔线展开**：主色短线用 wipe 擦除，作为标题与正文的节奏分界。

## 7b. 跨页流畅感编排（动态样稿提炼）

- **封面由内向外扩散序列**：中心轴点先 `zoom`/`appear` → 内圈环 `wipe`/`grow` 长出 →
  外圈环依次跟进 → 辐条/分弧最后落位；同组内 delay 由内向外错开 120–260ms，模拟点到面展开。
  描边连续生长在 2019 对象动画里无对应预设，用分段擦除/放大近似，不写描边生长节点。
- **母题全稿复现**：同一组圆环/细线/编号符号在封面、目录、内容页、过渡页、结尾重复出现，
  位置与颜色固定；章节过渡页复用同一母题，只换编号与章名。
- **动线统一**：全稿入场方向与转场方向保持一致（例如统一从左进入就 `push_l`/`fly_l`），
  不左右混排；L1 p14/Morph 转场按动线方向选预设。
- **跨页对象不是同一个实例**：2019 无跨页时间线，连续感靠「每页复现同款元素 + 同向转场」；
  真正的跨页补间只在 L1 Morph 配对成立时出现。

## 8. 版式禁忌与许可边界

- 不编造事实、经历、证书与统计数字；素材缺失信息用【】占位。
- 全篇无 emoji；语义图标用几何形状或编号承担。
- 非商业/个人学习许可的模板素材不可直接搬入公开演示稿；只参照其结构与配色思路，
  重画原生形状。
- MIT/Apache 规范思路可用；本地样稿库路径与协议台账见 `source-inventory.md`。

## 9. 配方级版式（ppt-effects 17 效果反查提炼）

> 下列为可复用的页型骨架与动效编排；参考件照片/占位文字不沿用，只抽结构。Morph 配对规则见
> `effects-catalog.md` 第 11.2 节。

- **模糊遮罩大字页**：满页模糊底图（PIL 预生成，半径 50、亮度 -10；PPT 艺术效果存 .wdp 查不到 XML）
  + 海报式大字阶梯（主标题 72 / 副标 36 / 正文 32 / 标签 28pt）；文字位移靠 Morph 序列，不另加对象动画。
- **扇形展开**：12 片扇形收拢于一侧，2 秒展开成扇面；竖排短标题自左滑入。扇面片用 pie/blockArc
  分段，轴心锁定规则同 effects-catalog 第 8 节。
- **六边形窗口页**：满页底图 + 白线六边形外框，图内再开六边形取景；主/副标题左右交替落位，
  逐页换图靠 Morph 推拉。
- **玻璃碎片散开**：四块「背景填充」玻璃叠起 → 散开 → 排成一行；可延伸为目录页与四栏拼贴。
- **中式斜切面板阵列**：同尺寸斜切面板（parallelogram）阵列，逐页滑入；每页色块异色、背景同色。
- **立体图片轮播**：顶部标签条（激活项高亮拉长）+ 主体大图 + 左下缩略图；图位按 A 大图 / B 小图 /
  C 小图（画布外左）/ D 大图（画布外右）分配，越界图位移出画布；推拉靠 Morph。
- **扫光单页**：梯形/组合体扫光 + 多段文字按序出现；关键帧密集的成稿只改文案（`a:t`），
  不重建形状，避免动画绑定失效。
- **加载指针**：七段变速陀螺旋（净转 0°）+ 标题淡入；指针分段用不同周期/方向，轴心锁定。
- **纵横导航栏**：顶栏或左栏双轴导航；导航项等距、左栏居中、顶栏右对齐，激活项拉长高亮；
  章 × 子页结构，导航项数随文案增减。
- **创意文字过渡 / 镂空金边 / 渐变过渡 / 破格立体**：设计师手法类，落到现有能力——斜切平行四边形
  叠层、描边镂空字、同色系深浅渐变底、卡片错位叠放加投影；不依赖未收录预设。

## 10. 工程坑位（反查实测记录）

- **图片填充位置**：整页背景图在 `p:bg/a:blipFill/a:blip`；形状/图片取景在 `p:sp` 或 `p:pic` 下的
  `blipFill/a:blip`（`p:pic` 的 blipFill 不在 spPr 里，按 spPr 查会静默空转）；换图优先改 rels 的 Target。
- **动画按 spid 绑定**：删形状、重建文本框会让对应动画失效；改文案只改 `a:t` 文本节点，不动
  `rPr` 字号字体与 `p:timing`。
- **画布外元素**：Morph 推拉与路径巡游用的负坐标大形状不要按「画布内」理解，也不要删除。
- **文案纪律**：按句给文本位，一段话塞一个位必然挤；封面主标题 ≤15 字；定宽文本框字号变大或
  字数变多会换行，位移落点按原文字宽度计算，换行即错位。
- **交付前全页渲染**：本地只看静帧，动画必须在 PowerPoint/WPS 里 F5 复核；结构问题先过
  `validate` 体检再谈观感。
